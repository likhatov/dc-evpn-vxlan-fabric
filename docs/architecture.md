# Архитектура сети и план адресации

## Логическая и физическая схема фабрики (CLOS)

Фабрика построена по 2-уровневой неблокируемой топологии **CLOS (Full-Mesh Leaf-Spine)**: каждый Leaf-коммутатор соединён с каждым Spine-коммутатором.

```text
                       +-----------------------+               +-----------------------+

                       |        spine-1        |               |        spine-2        |
                       |   Underlay AS 65000   |               |   Underlay AS 65000   |
                       |  Overlay RR AS 65000  |               |  Overlay RR AS 65000  |
                       |  lo:  10.255.0.101/32 |               |  lo:  10.255.0.102/32 |
                       |  lo1: 10.255.1.101/32 |               |  lo1: 10.255.1.102/32 |
                       +-----+-----------+-----+               +-----+-----------+-----+
                        eth1 |           | eth2                 eth1 |           | eth2
                 10.0.0.0/31 |           | 10.0.0.2/31   10.0.0.10/31|           | 10.0.0.12/31

                             |           +-------------+-------------+           |
                             |                         |                         |
                             |           +-------------+-------------+           |
                 10.0.0.1/31 |           | 10.0.0.11/31  10.0.0.3/31 |           | 10.0.0.13/31
                        eth1 |           | eth2                 eth1 |           | eth2
                       +-----+-----------+-----+               +-----+-----------+-----+

                       |        leaf-1         |               |        leaf-2         |
                       |   Underlay AS 65001   |               |   Underlay AS 65002   |
                       |   Overlay  AS 65000   |               |   Overlay  AS 65000   |
                       |  lo (VTEP): .0.1/32   |               |  lo (VTEP): .0.2/32   |
                       |  lo1 (BGP): .1.1/32   |               |  lo1 (BGP): .1.2/32   |
                       +-----+-----------+-----+               +-----+-----------+-----+
                        eth3 |           | eth4                 eth4 |           | eth3
                     VLAN 10 |           | VLAN 20           VLAN 20 |           | VLAN 30
                   (VRF_TEN_A)           | (VRF_TEN_A)   (VRF_TEN_A) |           | (VRF_TEN_B)

                             |           +-------+     +-------+     |           |
                             |                   |     |             |           |
                       +-----+-----+         +---+-----+---+         |     +-----+-----+

                       |  host-1   |         |   host-2    |         |     |  host-3   |
                       | Tenant A  |         |  Tenant A   |         |     | Tenant B  |
                       |10.10.10.1 |         |  10.10.20.2 |         |     |10.10.10.1 |
                       |GW: .10.254|         | GW: .20.254 |         |     |GW: .10.254|
                       +-----------+         |  LACP bond0 |         |     +-----------+

                                             | (EVPN-MH)   |         |  (IP пересекается
                                             +-------------+         |   с host-1 в др. VRF)
```

## План IP-адресации узлов и Loopback-интерфейсов

* **Underlay Loopbacks (`lo`):** `10.255.0.0/24` — Router-ID и источник VXLAN-туннелей (VTEP IP).
* **Overlay Loopbacks (`lo1`):** `10.255.1.0/24` — адреса пиринга iBGP L2VPN EVPN.
* **Underlay P2P линки:** `10.0.0.0/24` — подсети с маской `/31` (RFC 3021).

| Узел | Роль | Underlay ASN | Overlay ASN | `lo` (VTEP / RID) | `lo1` (iBGP EVPN) | OOB-интерфейс |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `spine-1` | Spine / Route Reflector | `65000` | `65000` | `10.255.0.101/32` | `10.255.1.101/32` | `eth0` (`VRF_MGMT`) |
| `spine-2` | Spine / Route Reflector | `65000` | `65000` | `10.255.0.102/32` | `10.255.1.102/32` | `eth0` (`VRF_MGMT`) |
| `leaf-1` | Leaf / VTEP | `65001` | `65000` | `10.255.0.1/32` | `10.255.1.1/32` | `eth0` (`VRF_MGMT`) |
| `leaf-2` | Leaf / VTEP | `65002` | `65000` | `10.255.0.2/32` | `10.255.1.2/32` | `eth0` (`VRF_MGMT`) |
